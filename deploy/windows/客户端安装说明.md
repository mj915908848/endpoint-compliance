# 终端合规客户端安装说明

## 安装前

客户端程序没有代码签名，安装时会以管理员身份运行。请从发布页下载 MSI，把文件放在只有自己和管理员能写入的文件夹里（例如自己的“下载”文件夹）。不要从共享目录或 `C:\` 下新建的文件夹安装：其他账号可能在你安装前替换掉里面的程序或脚本。

## 用 MSI 安装

1. 把 `compliance-client-<版本>-windows-x64.msi` 和管理员给的 `登记配置.json` 放在同一个文件夹。管理员在管理端“终端登记”页生成登记码，点“下载登记配置”得到这个文件。
2. 双击 MSI，在管理员提示中点“是”。
3. 装完弹出“登记到管理端”窗口：地址和登记码已自动填好（没有配置文件时手动填写），点“登记”，再在管理员提示中点“是”。
4. 看到“登记成功”即可关闭。约 1 分钟后管理端显示该终端在线。

关掉了登记窗口也没关系：托盘图标会显示“尚未登记”，右键选“登记到管理端…”即可。批量部署可用 `msiexec /i <MSI> SERVERURL=https://管理端域名 CODE=<登记码> /qn` 静默安装并登记。

## 升级

直接装新版本 MSI，登记身份和本地数据保留，不需要登记码。以前用 zip 包脚本装过的电脑也一样。管理端也可以在“系统设置”上传新版 MSI 远程下发升级。

## 卸载

在“设置 → 应用”里卸载“终端合规客户端”，会同时删除登记身份和本地数据。

## 常见问题

- **无法连接管理端**：在这台电脑的浏览器中打开管理端地址，打不开是 DNS 或网络问题，提示证书错误是证书问题。
- **终端被管理端删除**：托盘提示“本机已从管理端删除”时，检查和拦截照常进行，但结果无法上报。管理员生成新登记码后，在这台电脑上以管理员身份运行 `"C:\Program Files\ComplianceAgent\Compliance.Agent.exe" --enroll --server https://管理端域名 --code <登记码>`，约 1 分钟后作为新终端恢复上报。
- **登记失败**：登记码可能已过期、已撤销或可登记台数已用完，请管理员重新生成登记配置。
- **电脑时间不准**：与管理端相差超过 5 分钟时请求会被拒绝，请开启自动对时。
- **文件被 Windows 拦截**：经浏览器、聊天工具或邮件传来的安装包，先右键 →“属性”→ 勾选“解除锁定”再安装。
- **运行日志**：右键任务栏右下角的托盘图标，选“运行日志”；文件在 `C:\ProgramData\ComplianceAgent\logs\agent.log`，本机所有用户都能查看。
