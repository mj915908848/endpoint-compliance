# Windows 实机试用说明

本包为开发版（版本号见压缩包文件名），用于在真实 Windows 上试用和验证客户端。审计模式：只检查，不拦截、不卸载任何软件。

## 一、启动管理端

1. 把整个压缩包解压到一个目录，例如 `C:\合规试用\`。
2. 双击 `启动演示.bat`。
   - 管理端和客户端在同一台电脑：提示输入 IP 时直接回车。
   - 客户端在别的电脑上：输入本机的内网 IP（例如 `192.168.1.15`），并在 Windows 防火墙中允许 5080 端口。
3. 浏览器会打开管理页面。账号为 `admin`，密码在启动窗口提示的 `demo-login.txt` 文件中。
4. 试用期间保持这个窗口不要关闭。

## 二、安装常驻客户端（推荐）

1. 在管理页面进入“终端登记”，生成一个登记码并复制。
2. 在要检查的电脑上双击 `安装常驻客户端（试用）.bat`，在管理员确认中选择“是”。
3. 输入管理端地址（同一台电脑直接回车，否则输入 `http://<管理端IP>:5080`），再粘贴登记码。
4. 看到“安装完成”即可关闭窗口。

安装后客户端作为 Windows 服务在后台运行，开机自动启动，任务栏右下角会出现托盘图标：

- 约 1 分钟内管理端显示该终端在线，并完成首次完整检查；
- 之后每分钟上报心跳，每 5 分钟检查进程和代理，每小时完整检查一次；
- 在管理端设备详情点“请求重新检查”，客户端会在下一次心跳（约 1 分钟内）执行。

拿到新版本试用包后，再次双击 `安装常驻客户端（试用）.bat` 并选择“1 仅更新程序”，即可保留登记身份直接升级。

只想临时检查一次、不安装服务，可以改用 `本机采集试用.bat`。

## 三、需要核对的内容

在设备详情的“检查覆盖”标签页：

- 所有检查项最好都是“已完成”。如有“读取失败”，请截图“说明”一列。
- 重点看“应用商店应用”（每个用户一行）和“代理高级设置”（整机一行）。

对照测试（装好常驻客户端后，每做一项，在管理端点“请求重新检查”，约 1 分钟后刷新）：

| 测试 | 操作 | 预期 |
| --- | --- | --- |
| 商店应用 | 从 Microsoft Store 安装 Copilot（若已安装可跳过） | “全部证据”出现“应用商店应用（按用户）”，结论不通过 |
| 系统代理 | 管理员命令行执行 `netsh winhttp set proxy 127.0.0.1:7890`，测试后执行 `netsh winhttp reset proxy` 恢复 | 出现“WinHTTP 代理”证据 |
| 高级代理（Windows 11） | 管理员命令行执行 `netsh winhttp set advproxy setting-scope=machine settings={"Proxy":"127.0.0.1:7890","ProxyBypass":"","AutoconfigUrl":"","AutoDetect":false}`，测试后执行 `netsh winhttp reset advproxy` 恢复 | 出现“系统级代理设置”证据。**若没有出现，请反馈** |

## 四、升级后启用新的检测规则

新版本管理端自带的检测规则（新增产品、网卡白名单等）不会自动替换已发布的策略。升级管理端后，策略页面顶部会提示“管理端内置了更新的检测规则”：

1. 用 `admin` 登录，进入“策略管理”，点“载入内置最新规则”。
2. 点页面右上角的“保存并发布”，在弹窗中核对变更内容后确认发布。

策略页面也可以直接编辑：修改策略名称、运行模式、适用终端，添加、编辑或删除禁用产品，维护禁止访问的域名和已批准的网卡。改完同样点“保存并发布”。

客户端约 1 分钟内取得新策略，下一次检查即按新规则执行。

## 五、测试敏感文件名扫描

终端只比对文件和文件夹的**名称**，不打开、不上传文件内容。扫描范围是各用户目录和除系统盘外的本地固定磁盘（如 D 盘），不扫 U 盘和网络盘。

1. 先在被检查的电脑上准备测试文件，例如：
   - 桌面新建 `测试机密-报价单.txt`；
   - D 盘新建文件夹 `测试机密资料`（如有 D 盘）。
2. 管理页面进入“策略管理”，在“敏感文件扫描”面板打开“启用扫描”，点“添加敏感文件规则”：
   - 关键词填 `测试机密`；
   - 处理方式先选“只告警”。
3. 点右上角“保存并发布”并确认。
4. 客户端约 1 分钟内取得新策略，随后在后台扫描。NTFS 磁盘直接读取文件表，一百多万个文件约 10 秒；扫描完成后随下一次检查（每 5 分钟）上报。
5. 查看结果：
   - **告警中心**：每个命中路径一条“敏感文件”告警；
   - **终端详情 → 检查结果**：“敏感文件（N）”一节列出路径、命中的关键词和所属用户或磁盘；
   - **下载报告 → Markdown**：第 4 节“软件与敏感文件”有同样的表格；
   - “只告警”不改变终端结论。
6. 把规则改成“判定违规”再发布，等下一次检查后该终端结论变为“不通过”，告警中心顶部的“违规设备”里会出现它。
7. 之后再新建、删除或改名命中文件，不用手动操作：终端每 5 分钟读取一次磁盘的变更日志，有相关变化就重扫该盘，约 5–10 分钟内告警出现或自动解除。也可以在设备详情点“请求重新检查”立即全量重扫。

请顺便记录扫描耗时，以及扫描期间电脑是否明显变慢。耗时可以在客户端里查看：

1. 右键任务栏右下角的“终端合规通知”图标，选“运行日志（需管理员）”，在弹出的 Windows 确认框中点“是”（普通员工账户需输入管理员密码）。
2. 勾选“只看敏感文件扫描”，会看到类似“敏感文件扫描：C:\ 通过 NTFS 文件表比对 1349311 个名称，用时 7.3 秒”的行，每块磁盘一行；之后有变化触发重扫时也会记一行原因。
3. 不勾选时能看到客户端的全部运行记录：每次检查一行摘要、收到新策略、管理端请求重新检查、上报成功或失败。窗口每 5 秒自动刷新。

## 六、反馈内容

在设备详情点“下载报告 → Markdown 报告”，把文件发回即可。

## 七、卸载与清理

- 双击 `卸载常驻客户端.bat`：删除服务、托盘程序和客户端的登记身份及本地数据。
- 关闭 `启动演示.bat` 的窗口即停止管理端。管理端数据位于 `%LOCALAPPDATA%\CustomerComplianceDemo`，删除即清空。
- 如曾使用 `本机采集试用.bat`，另删除 `%ProgramData%\ComplianceAgentHttpTrial-*`。
