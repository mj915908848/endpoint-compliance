# 0.2 能力与验收矩阵

本表对应 `main` 分支；已发布版本见 [Releases](https://github.com/mj915908848/endpoint-compliance/releases)，比 `main` 晚的功能以发布说明为准。所有“构建”或“模拟”证据都不等同于Windows原生验收。此版为审计试点；完整设计的强制防护目标尚未全部实现。

| 能力 | 实现范围 | 尚需验收或开发 |
| --- | --- | --- |
| 平台 | 设备登记、签名请求、SQLite演示/PostgreSQL、报告、告警、角色/CSRF、签名策略、ScanNow | 客户内网部署、账号轮换/AD集成、持续容量压测 |
| 用户采集 | ProfileList显式SID/路径/HKU已加载用户；未加载注册表显示UNKNOWN，可读的个人目录仍检查扩展、CLI和常见安装位置 | Windows10/11实际构建、多用户/AzureAD、权限与异常场景；未加载用户的注册表不自动挂载 |
| 系统代理 | WinINET 用户设置、机器/用户持久代理环境变量、WinHTTP 基本配置（WinHttpGetDefaultProxyConfiguration）、整机与系统账户的 WinINet 连接设置（代理/PAC/自动检测）；不调用 netsh 等外部命令；采集进程自己的代理变量仅作线索；读取或解析失败时显示 UNKNOWN | Windows 11 `netsh winhttp set advproxy` 写入的高级代理与连接设置的对应关系待实机验证；WPAD 自动发现结果与其他代理机制；会话级 Process 环境变量不代表机器持久配置 |
| 安装/插件/CLI | 卸载登记、按用户的 Appx/MSIX 包（Windows PackageManager，按应用汇总所有版本，不调用 PowerShell）、Clash/Codex已知服务登记、卸载名称和常见安装目录名允许带版本号/架构后缀、目录名与exe双重匹配、各 NTFS 固定磁盘按文件表全盘查找规则中的程序文件名（文件信息里的产品名一致才确认，否则为线索）、VS Code/Cursor/Windsurf已知扩展目录、规则中的 npm 包和 pip/pipx/uv 包及已知用户CLI路径；损坏扩展清单不遮蔽后续清单，读取失败保留缺口 | 未知软件、其他服务/启动项、便携文件改名、非 NTFS 磁盘、PWA和新安装体系不承诺穷尽；企业例外管理待完善 |
| 端口与网卡 | IPv4/IPv6 监听端口及其所属进程（GetExtendedTcpTable）：已知产品进程监听的任意端口、其他进程占用的常见代理端口；隧道网卡按策略的产品特征归属，已批准网卡（如 aTrust）不报告；回环代理设置会写明监听该端口的程序；以上均只作线索 | UDP 监听、服务宿主进程（svchost）背后的具体服务、端口被短暂占用的情形 |
| 敏感文件 | 按策略关键词比对用户目录和系统盘以外本地磁盘中的文件、文件夹名称（支持中文，忽略大小写和全角半角；可限定扩展名和排除目录）；只上报路径、命中规则和所有者，不读取、不上传文件内容；后台低优先级扫描：NTFS 磁盘直接读取文件表（MFT），几秒内比对整盘名称，之后每个检查周期读取 USN 变更日志，只在出现、删除或移动了命中名称时重扫该磁盘，新文件几分钟内即可发现；非 NTFS 磁盘逐个目录扫描并按间隔重扫；结果跨重启保留，规则变化后重新扫描；每个范围上报数量有上限，超出时标明仅列出部分；规则默认“只告警”，逐个路径通知管理员、不提醒员工、不影响结论，改为“判定违规”后终端结论为不通过 | 大磁盘读取文件表的耗时与内存、文件夹改为云盘占位等仅改属性的变化（等间隔重扫）、BitLocker 锁定盘、OneDrive 等云盘占位文件、超长路径；不覆盖 U 盘、网络盘和文件内容 |
| 安全基线 | 策略启用后每次完整检查读取，每项单独作为一个检查项上报：杀毒软件与防火墙（Windows 安全中心 `WscGetSecurityProviderHealth`；无安全中心时防火墙改读三个配置文件的开关）、系统更新（最近一次安装的累积更新 RollupFix 的时间）、BitLocker（WMI `Win32_EncryptableVolume` 的系统盘保护状态）、自动锁屏（整机 `InactivityTimeoutSecs` 或已登录用户的屏幕保护设置，组策略优先）、来宾账户、本地管理员组成员（内置 Administrator、组和允许的账户不上报）、远程桌面（`fDenyTSConnections`，组策略优先）、SMBv1 服务端与客户端驱动；只读取，不修改；每项可选「只告警」或「判定违规」，后者读取失败时结论为无法判断；读不到的项目（如服务器版无安全中心、家庭版无 BitLocker）显示「未覆盖」 | 各 Windows 版本实机验收；电源设置里的「关闭显示器后需要登录」、动态锁、未登录用户的屏幕保护设置不在检查范围；第三方杀毒和防火墙依赖其向安全中心的注册 |
| 防篡改 | 常驻服务每分钟检查自身启动类型（被改为手动或禁用时用 `ChangeServiceConfig` 改回自动）、托盘的 HKLM `Run` 自启动项和任务管理器中的禁用标记（仅 MSI 安装，被删除或禁用时恢复）；服务被手动停止（区分系统关机和安装程序）、上次运行在同一次开机内未正常停止（被结束进程）、MSI 卸载时各产生「防篡改」告警，停止前 5 秒内上报；策略可设置卸载密码（浏览器计算 PBKDF2-SHA256 摘要，策略只含摘要），MSI 卸载（非升级）在停止服务前校验 `UNINSTALLPASSWORD`，缺失或错误时卸载失败回滚并告警；系统关机时上报，终端显示「已关机」，不产生失联告警 | 本机管理员可直接删除服务、注册表或强制结束后不再启动，只能事后从失联发现；休眠和睡眠仍按失联处理；卸载密码只在 MSI 卸载时校验，脚本安装的客户端不受保护 |
| 终端分组 | 每台终端最多属于一个分组（不区分大小写，最长 64 字符）；登记码可带分组，用它登记的终端自动归组；管理员在终端列表批量设置或移出分组（审计 `SetDeviceGroup`）；命名策略可按分组适用（逐台指定的终端优先，其次分组，其余用默认策略），一个分组只能用于一份策略；终端列表、告警按分组筛选，CSV 导出含分组 | 强制模式仍需逐台指定试点终端，不能按分组；分组只有一层，不支持嵌套或一台终端属于多个分组；分组由管理端维护，客户端不上报 |
| 资产清单 | 客户端在完整检查后读取硬件（WMI：厂商、型号、BIOS 序列号、处理器核心与线程、内存条容量、物理硬盘型号/介质/总线、固定分区剩余空间）、系统名称/版本号（含月度更新修订号）/版本（如 24H2）/安装时间/最近开机，以及“应用和功能”列出的软件（卸载注册表，全机和已登录用户各自安装的，不含系统组件和补丁）；有变化或满一天才上报；管理端「资产清单」页按终端看硬件、跨终端看软件（装在几台、各版本台数、装在哪些终端）和变更记录，终端详情有「资产」页签；硬件和软件清单可导出 Excel（审计 `ExportAssets`、`ExportSoftware`）；变更记录保留一年 | 不含应用商店（MSIX）应用、绿色软件和浏览器扩展；未登录用户自己安装的软件要等其登录后才能读到；固件占位序列号（如 “To be filled by O.E.M.”）显示为未读到；不采集显示器、外设和软件许可证 |
| 多管理员与两步验证 | 账号管理员（`Admin` 角色）在「系统设置 → 账号」新建账号、修改角色、重置密码、重置两步验证、停用或启用账号（停用的账号不能登录、已登录的会话立即失效，账号保留以便审计记录对得上人）；每个账号可在账号菜单启用 TOTP 两步验证（RFC 6238，30 秒 6 位，兼容 Microsoft/Google Authenticator、腾讯身份验证器等），登录时密码正确后再要求验证码，验证码只能用一次，输错计入登录失败次数；账号管理员可要求所有账号启用，未启用的账号登录后只能先完成设置；不能停用自己或去掉最后一个账号管理员；启动配置里同时有 Operator 和 Publisher 的账号自动获得 Admin | 没有恢复码：唯一的账号管理员丢失手机时需在数据库里清空其 `users.totp_secret`；验证器密钥以明文存于数据库；不支持 LDAP/AD、单点登录或短信验证码 |
| 日志外发（Syslog / SIEM） | 账号管理员在「系统设置 → 日志外发」设置；每 10 秒把新产生、重新出现和已恢复的告警以及新的审计记录按顺序发出，RFC 5424 格式，消息体为 JSON 或 CEF；UDP（RFC 5426）、TCP（每行一条）或 TLS（RFC 5425 octet counting，校验证书和名称，可另外信任粘贴的内部 CA）；设施 local0–local7，告警按类型映射严重级别（防篡改、违规为 warning，登录失败为 notice）；发送失败下次重试，进度保存在数据库，重启不丢、不重发；开启前的记录不补发；页面可发送测试消息并显示最近一次结果 | UDP 不保证送达；TCP/TLS 每轮新建连接，不支持客户端证书；终端检查报告和证据明细不外发；单条 UDP 消息超过 8 KB 会被截断 |
| 离线 | SQLite跨重启序号、补报ACK、去重和隔离 | 真实断电/磁盘耗尽、队列压力和系统性能 |
| 通知 | 平台告警中心、普通用户托盘列表/确认 | 无SMTP/企业聊天适配器；本机免打扰/多会话展示实测 |
| 发现即结束进程 | 强制模式下每 2 秒检查，程序名与产品名双重确认后结束进程树；托盘提示员工、管理端产生拦截告警；审计模式下报告「可启用」，未就绪时拒绝发布强制策略 | 改名且去掉版本信息的程序、短于 2 秒的运行、启动前阻止（需 AppLocker/WDAC） |
| 浏览器网址拦截 | 强制模式下写入 Edge、Chrome 的 URLBlocklist 组策略（保留他人条目，编号不连续也不丢，停用时只删除自己写入的），读回核对后报告「已生效」；「已生效」指注册表配置正确，不代表已做访问测试 | Firefox、便携浏览器、被域组策略覆盖的情形、浏览器刷新时机 |
| 移动存储管控 | 策略 `usb.storage` 为 `Allow`/`ReadOnly`/`Block`，`usb.allowedDevices` 按设备实例 ID 的一段（序列号或 `PROD_型号`，不区分大小写）放行；客户端每 2 秒枚举父设备在 USB 总线上的磁盘（U 盘、读卡器、USB/UAS 移动硬盘）。强制模式且勾选「移动存储管控」时：禁止 = 设备管理器“禁用设备”（不跨重启，客户端开机后再次执行），只读 = 磁盘只读属性（不跨重启）并卸载其分区让 Windows 以只读重新装载；用户收到托盘提示。插入、拔出、拦截都上报为记录（`UsbConnected`/`UsbRemoved`/`UsbBlocked`），拦截另产生告警；审计模式只记录并注明策略本应如何处理。记录在「资产清单 → 移动存储记录」和终端详情「移动存储」页签，可导出（审计 `ExportUsbEvents`），保留一年；客户端只恢复自己停用或设为只读的设备，卸载客户端时一并恢复 | 插入到生效之间约 2 秒；正在使用的设备无法停用，会报告错误并每 2 秒重试；不管控手机（MTP）、光驱、网络共享和蓝牙传输；本机管理员可在设备管理器中重新启用，下次检查时会再次停用；尚未在实体 U 盘上做过端到端验证 |
| 例外审批 | 托盘“申请例外…”列出本机可申请的项：策略禁止且本机已确认发现（安装、进程或扩展）的软件，以及接入过、按策略不能读写的 U 盘；员工填理由（≤300 字）和天数（1–90）提交，服务以调用者的 Windows 账号记录申请人，同一项 10 分钟内只能提交一次。申请作为 `ExceptionRequest` 事件上报，服务器保存为待审批并产生“例外申请”告警（可推送）。发布人在「例外审批」页批准（可改天数，从批准时起算）、驳回或撤销已生效的例外，也可不经申请直接新增；审计 `CreateException`/`ApproveException`/`RejectException`/`RevokeException`，处理后申请告警自动关闭。生效中的例外写入每份策略的 `exceptions`（重新签发，版本号不变），客户端只应用本机的：判定时不计违规并在报告中注明“已批准例外，有效至…”，强制模式下不结束该软件进程，该 U 盘按放行处理；批准后一天内托盘提示“已批准”。到期后判定与管控自动恢复，服务器每小时把过期例外移出策略 | 驳回不会通知员工；例外按终端，不按用户；只能为策略已有的软件申请；托盘申请窗口尚未在实体机上验证 |
| 合规报表 | 「合规报表」页按日期范围（本周/上周/本月/上月/自选，≤366 天，最近 400 天内）统计：期初与期末各终端结论（每天按当天结束时的最新结论，与概览趋势同一口径）、每日趋势、按终端现在所在分组的排名（合规率低的在前）、期间有效的违规/敏感文件/基线/防篡改/健康/拦截告警按问题汇总的前 20 项、目前不通过的终端及开始不通过的时间（≥7 天标超期，最多 100 台）、期间新增告警按类型计数。浏览器打印或另存 PDF；下载 Markdown 审计 `ExportReport`。告警推送可设定期报表：每周一 9:00 推送上周、每月 1 日 9:00 推送上月的摘要和报表链接，按服务器所在时区，同一期只推一次 | 不发邮件（无 SMTP）；分组按现在的分组而非当时；超过保留期限被清理的告警不计入；PDF 由浏览器生成 |
| 通用API | 明确标未覆盖 | 客户出口或本机Web过滤适配，外出/备用出口/QUIC/ECH等验证 |
| 安装升级 | 按机器安装的 MSI（服务 + 托盘，主版本升级保留登记和本地数据，拒绝降级，卸载清理数据目录）；远程升级：管理端用策略签名密钥签名托管的 MSI，终端核对签名、SHA-256 和版本后安装；可先升指定台数（在线的优先），终端装完后回报成功或安装程序的错误码，管理端按终端显示升级进度；策略签名密钥轮换；管理端 Docker 镜像与离线镜像包随版本发布 | MSI 与程序的 Authenticode 代码签名及发布者校验、失败率高时自动暂停、原生安装长期验证 |
| 可配置HTTP试用 | 显式指定回环或私有 IPv4 地址与端口，安装为常驻服务（`httpTrial` 配置，仅接受声明试用模式的内网 HTTP 管理端）；用于本地演示和 Windows 冒烟测试 | 内网 HTTP 明文传输；正式部署必须使用 HTTPS |
| 运维 | 状态/操作审计、数据库事务与备份说明；终端可批量归档或删除，默认 30 天未上线自动归档，重新上线自动恢复；客户端每次心跳上报自身运行状况（待上报积压、被拒收、队列丢弃、结束程序出错），异常时产生「设备健康」告警 | 留存自动清理、监控告警集成、备份恢复实测 |

审计检查可以在声明范围内通过；界面防护状态依然标未强制。规则已写入/文件已下载不是阻断验证。未知或缺失覆盖不能强行改为通过。
