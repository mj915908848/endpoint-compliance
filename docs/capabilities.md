# 0.1.0 能力与验收矩阵

所有“构建”或“模拟”证据都不等同于Windows原生验收。此版为审计试点；完整设计的强制防护目标尚未全部实现。

| 能力 | 实现范围 | 尚需验收或开发 |
| --- | --- | --- |
| 平台 | 设备登记、签名请求、SQLite演示/PostgreSQL、报告、告警、角色/CSRF、签名策略、ScanNow | 客户内网部署、账号轮换/AD集成、持续容量压测 |
| 用户采集 | ProfileList显式SID/路径/HKU已加载用户；未加载注册表显示UNKNOWN，可读的个人目录仍检查扩展、CLI和常见安装位置 | Windows10/11实际构建、多用户/AzureAD、权限与异常场景；未加载用户的注册表不自动挂载 |
| 系统代理 | WinINET 用户设置、机器/用户持久代理环境变量、WinHTTP 基本配置（WinHttpGetDefaultProxyConfiguration）、整机与系统账户的 WinINet 连接设置（代理/PAC/自动检测）；不调用 netsh 等外部命令；采集进程自己的代理变量仅作线索；读取或解析失败时显示 UNKNOWN | Windows 11 `netsh winhttp set advproxy` 写入的高级代理与连接设置的对应关系待实机验证；WPAD 自动发现结果与其他代理机制；会话级 Process 环境变量不代表机器持久配置 |
| 安装/插件/CLI | 卸载登记、按用户的 Appx/MSIX 包（读取 AppxAllUserStore，未登录用户同样覆盖，不调用 PowerShell）、Clash/Codex已知服务登记、常见安装目录的目录名与exe双重匹配、VS Code/Cursor/Windsurf已知扩展目录、npm包及已知用户CLI路径；损坏扩展清单不遮蔽后续清单，读取失败保留缺口 | 未知软件、其他服务/启动项、便携文件改名、任意目录、PWA和新安装体系不承诺穷尽；企业例外管理待完善 |
| 端口与网卡 | IPv4/IPv6 监听端口及其所属进程（GetExtendedTcpTable）：已知产品进程监听的任意端口、其他进程占用的常见代理端口；隧道网卡按策略的产品特征归属，已批准网卡（如 aTrust）不报告；回环代理设置会写明监听该端口的程序；以上均只作线索 | UDP 监听、服务宿主进程（svchost）背后的具体服务、端口被短暂占用的情形 |
| 敏感文件 | 按策略关键词比对用户目录和系统盘以外本地磁盘中的文件、文件夹名称（支持中文，忽略大小写和全角半角；可限定扩展名和排除目录）；只上报路径、命中规则和所有者，不读取、不上传文件内容；后台低优先级按间隔扫描，结果跨重启保留，规则变化后重新扫描；每个范围上报数量有上限，超出时标明仅列出部分；规则默认“只告警”，逐个路径通知管理员、不提醒员工、不影响结论，改为“判定违规”后终端结论为不通过 | Windows 实机扫描耗时与磁盘负载、BitLocker 锁定盘、OneDrive 等云盘占位文件、超长路径；不覆盖 U 盘、网络盘和文件内容 |
| 离线 | SQLite跨重启序号、补报ACK、去重和隔离 | 真实断电/磁盘耗尽、队列压力和系统性能 |
| 通知 | 平台告警中心、普通用户托盘列表/确认 | 无SMTP/企业聊天适配器；本机免打扰/多会话展示实测 |
| 应用强制 | 精确哈希规则审查工件，未验证时拒绝完整强制发布 | AppLocker/WDAC原生安全合并、加载、真实阻断、回滚；目前未实现自动执行 |
| 网站强制 | Edge域名编译与注册表读取、规则审查工件 | 安全应用/例外合并、Edge各受管配置文件真实阻断；目前未实现自动执行 |
| 通用API | 明确标未覆盖 | 客户出口或本机Web过滤适配，外出/备用出口/QUIC/ECH等验证 |
| 安装升级 | Windows自包含服务/托盘测试ZIP和管理员安装脚本 | 代码签名、MSI、版本升级回滚、原生安装验证 |
| 可配置HTTP试用 | 显式指定回环或私有 IPv4 地址与端口；可一次性采集（独立身份目录），也可安装为常驻服务（`httpTrial` 配置，仅接受声明试用模式的内网 HTTP 管理端） | 内网 HTTP 明文传输；正式部署必须使用 HTTPS |
| 运维 | 状态/操作审计、数据库事务与备份说明 | 留存自动清理、监控告警集成、备份恢复实测 |

审计检查可以在声明范围内通过；界面防护状态依然标未强制。规则已写入/文件已下载不是阻断验证。未知或缺失覆盖不能强行改为通过。
