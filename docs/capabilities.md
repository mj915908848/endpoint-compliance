# 0.1.0 能力与验收矩阵

所有“构建”或“模拟”证据都不等同于Windows原生验收。此版为审计试点；完整设计的强制防护目标尚未全部实现。

| 能力 | 实现范围 | 尚需验收或开发 |
| --- | --- | --- |
| 平台 | 设备登记、签名请求、SQLite演示/PostgreSQL、报告、告警、角色/CSRF、签名策略、ScanNow | 客户内网部署、账号轮换/AD集成、持续容量压测 |
| 用户采集 | ProfileList显式SID/路径/HKU已加载用户，未加载/失败显示UNKNOWN | Windows10/11实际构建、多用户/AzureAD、权限与异常场景 |
| 系统代理 | WinINET 用户设置、WinHTTP 基本配置及高级配置/PAC；高级命令不可用或不可解析时显示 UNKNOWN | WinHTTP 高级配置各 Windows 版本实机兼容性、WPAD 自动发现结果与其他代理机制 |
| 安装/插件/CLI | 登记/精确包与插件ID、已知路径、元数据 | 未知软件、便携文件改名、任意目录和新安装体系不承诺穷尽；企业例外管理待完善 |
| 端口 | 本机已知代理端口监听线索 | 完整IPv4/IPv6 PID映射、网络接口线索及更广采集待增强 |
| 离线 | SQLite跨重启序号、补报ACK、去重和隔离 | 真实断电/磁盘耗尽、队列压力和系统性能 |
| 通知 | 平台告警中心、普通用户托盘列表/确认 | 无SMTP/企业聊天适配器；本机免打扰/多会话展示实测 |
| 应用强制 | 精确哈希规则审查工件，未验证时拒绝完整强制发布 | AppLocker/WDAC原生安全合并、加载、真实阻断、回滚；目前未实现自动执行 |
| 网站强制 | Edge域名编译与注册表读取、规则审查工件 | 安全应用/例外合并、Edge各受管配置文件真实阻断；目前未实现自动执行 |
| 通用API | 明确标未覆盖 | 客户出口或本机Web过滤适配，外出/备用出口/QUIC/ECH等验证 |
| 安装升级 | Windows自包含服务/托盘测试ZIP和管理员安装脚本 | 代码签名、MSI、版本升级回滚、原生安装验证 |
| 可配置HTTP试用 | 显式指定回环或私有 IPv4 地址与端口；管理员一次性原生采集、独立身份目录；不安装服务 | Windows 实机采集与权限验收；内网 HTTP 明文传输；真实常驻服务仍需 HTTPS |
| 运维 | 状态/操作审计、数据库事务与备份说明 | 留存自动清理、监控告警集成、备份恢复实测 |

审计检查可以在声明范围内通过；界面防护状态依然标未强制。规则已写入/文件已下载不是阻断验证。未知或缺失覆盖不能强行改为通过。
