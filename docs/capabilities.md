# 0.2 能力与验收矩阵

本表对应 `main` 分支；已发布版本见 [Releases](https://github.com/mj915908848/endpoint-compliance/releases)，比 `main` 晚的功能以发布说明为准。所有“构建”或“模拟”证据都不等同于Windows原生验收。此版为审计试点；完整设计的强制防护目标尚未全部实现。

| 能力 | 实现范围 | 尚需验收或开发 |
| --- | --- | --- |
| 平台 | 设备登记、签名请求、SQLite演示/PostgreSQL、报告、告警、角色/CSRF、签名策略、ScanNow | 客户内网部署、账号轮换/AD集成、持续容量压测 |
| 用户采集 | ProfileList显式SID/路径/HKU已加载用户；未加载注册表显示UNKNOWN，可读的个人目录仍检查扩展、CLI和常见安装位置 | Windows10/11实际构建、多用户/AzureAD、权限与异常场景；未加载用户的注册表不自动挂载 |
| 系统代理 | WinINET 用户设置、机器/用户持久代理环境变量、WinHTTP 基本配置（WinHttpGetDefaultProxyConfiguration）、整机与系统账户的 WinINet 连接设置（代理/PAC/自动检测）；不调用 netsh 等外部命令；采集进程自己的代理变量仅作线索；读取或解析失败时显示 UNKNOWN | Windows 11 `netsh winhttp set advproxy` 写入的高级代理与连接设置的对应关系待实机验证；WPAD 自动发现结果与其他代理机制；会话级 Process 环境变量不代表机器持久配置 |
| 安装/插件/CLI | 卸载登记、按用户的 Appx/MSIX 包（Windows PackageManager，按应用汇总所有版本，不调用 PowerShell）、Clash/Codex已知服务登记、卸载名称和常见安装目录名允许带版本号/架构后缀、目录名与exe双重匹配、各 NTFS 固定磁盘按文件表全盘查找规则中的程序文件名（文件信息里的产品名一致才确认，否则为线索）、VS Code/Cursor/Windsurf已知扩展目录、规则中的 npm 包和 pip/pipx/uv 包及已知用户CLI路径；损坏扩展清单不遮蔽后续清单，读取失败保留缺口 | 未知软件、其他服务/启动项、便携文件改名、非 NTFS 磁盘、PWA和新安装体系不承诺穷尽；企业例外管理待完善 |
| 端口与网卡 | IPv4/IPv6 监听端口及其所属进程（GetExtendedTcpTable）：已知产品进程监听的任意端口、其他进程占用的常见代理端口；隧道网卡按策略的产品特征归属，已批准网卡（如 aTrust）不报告；回环代理设置会写明监听该端口的程序；以上均只作线索 | UDP 监听、服务宿主进程（svchost）背后的具体服务、端口被短暂占用的情形 |
| 敏感文件 | 按策略关键词比对用户目录和系统盘以外本地磁盘中的文件、文件夹名称（支持中文，忽略大小写和全角半角；可限定扩展名和排除目录）；只上报路径、命中规则和所有者，不读取、不上传文件内容；后台低优先级扫描：NTFS 磁盘直接读取文件表（MFT），几秒内比对整盘名称，之后每个检查周期读取 USN 变更日志，只在出现、删除或移动了命中名称时重扫该磁盘，新文件几分钟内即可发现；非 NTFS 磁盘逐个目录扫描并按间隔重扫；结果跨重启保留，规则变化后重新扫描；每个范围上报数量有上限，超出时标明仅列出部分；规则默认“只告警”，逐个路径通知管理员、不提醒员工、不影响结论，改为“判定违规”后终端结论为不通过 | 大磁盘读取文件表的耗时与内存、文件夹改为云盘占位等仅改属性的变化（等间隔重扫）、BitLocker 锁定盘、OneDrive 等云盘占位文件、超长路径；不覆盖 U 盘、网络盘和文件内容 |
| 安全基线 | 策略启用后每次完整检查读取，每项单独作为一个检查项上报：杀毒软件与防火墙（Windows 安全中心 `WscGetSecurityProviderHealth`；无安全中心时防火墙改读三个配置文件的开关）、系统更新（最近一次安装的累积更新 RollupFix 的时间）、BitLocker（WMI `Win32_EncryptableVolume` 的系统盘保护状态）、自动锁屏（整机 `InactivityTimeoutSecs` 或已登录用户的屏幕保护设置，组策略优先）、来宾账户、本地管理员组成员（内置 Administrator、组和允许的账户不上报）、远程桌面（`fDenyTSConnections`，组策略优先）、SMBv1 服务端与客户端驱动；只读取，不修改；每项可选「只告警」或「判定违规」，后者读取失败时结论为无法判断；读不到的项目（如服务器版无安全中心、家庭版无 BitLocker）显示「未覆盖」 | 各 Windows 版本实机验收；电源设置里的「关闭显示器后需要登录」、动态锁、未登录用户的屏幕保护设置不在检查范围；第三方杀毒和防火墙依赖其向安全中心的注册 |
| 离线 | SQLite跨重启序号、补报ACK、去重和隔离 | 真实断电/磁盘耗尽、队列压力和系统性能 |
| 通知 | 平台告警中心、普通用户托盘列表/确认 | 无SMTP/企业聊天适配器；本机免打扰/多会话展示实测 |
| 发现即结束进程 | 强制模式下每 2 秒检查，程序名与产品名双重确认后结束进程树；托盘提示员工、管理端产生拦截告警；审计模式下报告「可启用」，未就绪时拒绝发布强制策略 | 改名且去掉版本信息的程序、短于 2 秒的运行、启动前阻止（需 AppLocker/WDAC） |
| 浏览器网址拦截 | 强制模式下写入 Edge、Chrome 的 URLBlocklist 组策略（保留他人条目，编号不连续也不丢，停用时只删除自己写入的），读回核对后报告「已生效」；「已生效」指注册表配置正确，不代表已做访问测试 | Firefox、便携浏览器、被域组策略覆盖的情形、浏览器刷新时机 |
| 通用API | 明确标未覆盖 | 客户出口或本机Web过滤适配，外出/备用出口/QUIC/ECH等验证 |
| 安装升级 | 按机器安装的 MSI（服务 + 托盘，主版本升级保留登记和本地数据，拒绝降级，卸载清理数据目录）；远程升级：管理端用策略签名密钥签名托管的 MSI，终端核对签名、SHA-256 和版本后安装；可先升指定台数（在线的优先），终端装完后回报成功或安装程序的错误码，管理端按终端显示升级进度；策略签名密钥轮换；管理端 Docker 镜像与离线镜像包随版本发布 | MSI 与程序的 Authenticode 代码签名及发布者校验、失败率高时自动暂停、原生安装长期验证 |
| 可配置HTTP试用 | 显式指定回环或私有 IPv4 地址与端口，安装为常驻服务（`httpTrial` 配置，仅接受声明试用模式的内网 HTTP 管理端）；用于本地演示和 Windows 冒烟测试 | 内网 HTTP 明文传输；正式部署必须使用 HTTPS |
| 运维 | 状态/操作审计、数据库事务与备份说明；终端可批量归档或删除，默认 30 天未上线自动归档，重新上线自动恢复；客户端每次心跳上报自身运行状况（待上报积压、被拒收、队列丢弃、结束程序出错），异常时产生「设备健康」告警 | 留存自动清理、监控告警集成、备份恢复实测 |

审计检查可以在声明范围内通过；界面防护状态依然标未强制。规则已写入/文件已下载不是阻断验证。未知或缺失覆盖不能强行改为通过。
